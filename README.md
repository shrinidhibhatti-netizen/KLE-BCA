# KLE BCA — Official College Website

Welcome to the official, modern, and interactive website for **KLE BCA** (K.L.E. Society's College of Computer Applications) — designed and developed with a pristine **White and Light Blue** aesthetic.

## 🏛️ Brand Identity & Color System

- **Brand Name:** KLE BCA (K.L.E. Society's College of Computer Applications)
- **Heritage:** Founded in 1916 by the Seven Saptarshis; over 108+ years of academic excellence and 290+ institutions worldwide.
- **Accreditation:** Autonomous Institution, NAAC 'A+' Grade (3.62 CGPA), Approved by AICTE, Affiliated to Rani Channamma / Karnatak University.
- **Core Aesthetic:** Modern, clean, tech-forward collegiate design dominated by **White & Light Blue**:
  - **Pure Crisp White (`#FFFFFF`, `#F8FAFC`):** Primary backgrounds, clean surfaces, high-contrast clarity.
  - **Soft Sky & Ice Blues (`#F0F7FF`, `#E0F2FE`, `#BAE6FD`):** Subtle section gradients, card backgrounds, and accent borders.
  - **Vibrant Cyan / Light Sky (`#38BDF8`):** Glow indicators, hover accents, and terminal badges.
  - **Brand Primary Blue (`#0284C7`, `#0369A1`):** High-readability headings, buttons, and brand emblems.
  - **Deep Navy Slate (`#0F172A`, `#1E293B`):** Text contrast and code terminal sandbox.

## 🚀 Key Brand & College Features

1. **High-Impact Hero with Live Interactive Code Terminal:**
   - Features real syntax-highlighted code tabs for *AI & Deep Learning (PyTorch)*, *React Full-Stack*, and *DevOps & Cloud Architecture (Terraform)*.

5. **Industry 4.0 BCA Specializations & Curriculum Explorer:**
   - 4 specialized computing tracks under NEP 2020:

## 🌐 How to Run Locally

You can launch a local web server in this directory using Python:

```bash
# In PowerShell:
python -m http.server 8080
```

Then open in any modern browser:
- **Local URL:** [http://localhost:8080](http://localhost:8080)
- **Or open directly:** Double-click [`index.html`](file:///c:/Users/student/Desktop/Shri/index.html)
